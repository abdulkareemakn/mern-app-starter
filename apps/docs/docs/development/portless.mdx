---
title: Portless
description: Stable HTTPS URLs for the workspace development apps.
---

`pnpm dev` runs Portless from the repository root. It starts every workspace
package with a `dev` script and assigns these URLs:

| App | URL |
| --- | --- |
| Client | `https://mern.localhost` |
| API | `https://api.mern.localhost` |
| Docs | `https://docs.mern.localhost` |

The names and fixed internal ports are in the root `portless.json`. Portless
terminates local TLS; the apps themselves still receive plain HTTP traffic.

On first use, approve the certificate-authority prompt. If you skip it, run:

```sh
pnpm exec portless trust
```

Use the client URL in a browser. Vite proxies `/api` to Express, preserving the
same-origin authentication cookies. The API URL is useful for direct endpoint
checks, such as `https://api.mern.localhost/api/health`.

## Direct development servers

To bypass Portless temporarily, run:

```sh
PORTLESS=0 pnpm dev
```

The direct client and docs servers use their usual localhost ports. The normal
`APP_URL` and `BETTER_AUTH_URL` values target `https://mern.localhost`; change
both to `http://localhost:3000` in your local `.env` when testing this mode.

Use `pnpm exec portless doctor` to diagnose local certificates, hostname
resolution, routes, and proxy state.
