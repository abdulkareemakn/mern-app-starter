## In development

TODO: Trace the path:

1. The browser calls `/api/...` on port 3000.
2. Vite proxies `/api` to Express on port 3001, so the browser stays on one origin.
3. Express middleware assigns `x-mern-client-ip` and Better Auth reads the session.
4. The route handler reads or writes MongoDB through Mongoose.
5. The handler responds with JSON that matches a shared contract type.

```text
Browser ──▶ Vite (3000) ──/api──▶ Express (3001) ──▶ MongoDB
```
